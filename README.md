# Memory-game

RS School vanilla JS task
[Task](https://github.com/rolling-scopes-school/tasks/tree/master/tasks/memory-game)

## Description

A simple **Memory Game** built with vanilla JavaScript, HTML, and CSS.

The goal of the game is to find all matching pairs of cards. The cards are flipped two at a time, and matching pairs remain open.

## How to run locally

No additional installation or build commands are required.

1. Clone or download the repository.
2. Open the project in **Visual Studio Code**.
3. Start the project using the **Live Server** extension.
4. Open the provided local URL in your browser.
